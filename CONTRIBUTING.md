# Contributing to WIRK

Thank you for your interest in contributing to WIRK! We welcome contributions from developers of all skill levels.

## 🛠️ Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/BilalSabugar/wirk-opensource.git
   cd wirk-opensource
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the Vite development server:
   ```bash
   npm run dev
   ```

## 🌿 Branching Strategy

- `master` / `main`: Stable production branch.
- Feature branches: `feature/your-feature-name`
- Bug fix branches: `fix/your-fix-name`

## 📝 Commit Conventions

We follow Conventional Commits:
- `feat: add new calendar timeline view`
- `fix: resolve mobile bottom navigation clipping`
- `docs: update BYOK instructions in README`
- `style: refine frosted glass border highlights`

## 🧪 Testing

Before submitting a PR, verify your changes compile cleanly:
```bash
npm run build
```
