Built from the ground up with **Apple-inspired fluid dynamics**, frosted glass optics, and zero-knowledge privacy, WIRK unifies **Kanban velocity**, **Pomodoro deep-work telemetry**, **encrypted daily reflections**, and an **autonomous AI companion (ARIA)** into a single, cohesive command center.

## 🚀 Quick Start (Local-First in 60 Seconds)

WIRK Community runs **100% locally in your browser** with zero external database configuration required.

### 1. Clone the repository
```bash
git clone https://github.com/aethronlabs/wirk.git
cd wirk
```

### 2. Install dependencies
```bash
npm install
```

### 3. Launch development server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser and click **"Launch Local Workspace (Zero Setup)"**. That's it!

## 🔑 AI Setup (Bring Your Own Key — BYOK)

WIRK Community connects directly from your browser to Google Gemini without requiring any intermediate server.

1. Get a free Google Gemini API key from **[Google AI Studio](https://aistudio.google.com/app/apikey)**.
2. In WIRK, open Settings by clicking your **Avatar** or pressing **`P`**.
3. Select the **AI Keys & BYOK** tab.
4. Paste your API key, select your preferred model (`gemini-2.5-flash` recommended), and click **Test & Save Key**.
5. Your key is stored securely in your browser's `localStorage` and never transmitted to any third party.
